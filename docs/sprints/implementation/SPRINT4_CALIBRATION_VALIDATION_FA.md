# VisionQC 4.3 — Sprint 4: Calibration & Validation

## هدف
تبدیل خروجی شاخص‌ها از تخمین آزمایشگاهی به فرایند قابل ممیزی برای اعتبارسنجی با داده برچسب‌خورده کارخانه.

## قابلیت‌های پیاده‌سازی‌شده
- صفحه مستقل `Calibration & Validation` در منوی Configuration.
- ثبت عکس و ویدئو با پنج برچسب مرجع: سالم، انحراف جزئی، هشدار متوسط، هشدار سطح بالا و بحرانی.
- ذخیره نام کارشناس QC، کد Batch و یادداشت هر نمونه در SQLite.
- اجرای همان Runtime و Detectorهای Production روی کل Dataset.
- محاسبه Accuracy، Precision، Recall، Specificity، F1، FPR و FNR.
- ماتریس آشفتگی پنج‌کلاسه و Recall هر کلاس.
- تحلیل جداگانه هر Metric، میانه هر کلاس، جداسازی و پیشنهاد آستانه.
- Production Gate بر اساس حداقل نمونه، پوشش کلاس‌ها، توافق با کارشناس و نرخ از دست‌رفتن عیب.
- تأیید نهایی انسانی QC و ثبت نام و زمان تأیید.
- جلوگیری از انتشار Template در Production تا وجود Validation پاس‌شده و تأییدشده برای همان نسخه.

## اصل ایمنی
آستانه‌های پیشنهادی به‌صورت خودکار روی Template اعمال نمی‌شوند. مسئول QC باید داده‌ها، خطاها و پیشنهادها را بررسی کند و سپس نسخه Template را تأیید کند.

## مسیر استفاده
`Navigate → Configuration → Calibration & Validation`

## نکته عملی
برای اعتبارسنجی صنعتی واقعی باید داده‌های همان محصول، دوربین، نور، زاویه، خط و مرحله فرایند استفاده شوند. داده‌های مصنوعی صرفاً برای تست نرم‌افزار مناسب‌اند و جایگزین Validation کارخانه نیستند.
