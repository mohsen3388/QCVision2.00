# VisionQC 2.0 — Sprint 6: Predictive Quality

Sprint 6 adds an offline, explainable early-warning layer over Factory Memory.

## Delivered
- short-horizon reject-risk forecast
- current versus baseline reject comparison
- repeated-defect and consecutive-reject detection
- process-drift analysis against accepted cases
- risk bands, confidence, evidence and limitations
- recommended controlled actions
- Predictive Quality user interface
- Voice AI integration
- domain events for forecast and early warning

## Safety boundary
The forecast is decision support. It does not predict mechanical failure, replace SPC, or authorize recipe/process changes without qualified review.
