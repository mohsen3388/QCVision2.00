# VisionQC 4.4 — Sprint 5: Factory Memory & Root-Cause Learning

این اسپرینت حلقه یادگیری کارخانه را تکمیل می‌کند:

Inspection → Defect → QC-confirmed Cause → Corrective Action → Effectiveness Verification → Learned Recommendation

## قابلیت‌ها
- داشبورد یادگیری کارخانه برای علل، عیوب، دستگاه‌ها و شیفت‌های پرتکرار
- محاسبه نرخ تکرار عیب و نرخ اثربخشی اقدامات دارای نتیجه
- پیشنهاد اقدام بر اساس موارد مشابه و فقط موارد تأییدشده QC
- ثبت نتیجه موثر/ناموثر برای اقدام اصلاحی در سرویس Factory Memory
- ثبت محدودیت حجم داده و جلوگیری از ادعای علیت خودکار

## قواعد ایمنی علمی
- علت ریشه‌ای فقط توسط QC تأیید می‌شود.
- پیشنهاد اقدام نقش Advisory دارد.
- داده کم با هشدار محدودیت نمایش داده می‌شود.
- اثربخشی فقط از Actionهایی محاسبه می‌شود که نتیجه موثر/ناموثر ثبت‌شده دارند.
