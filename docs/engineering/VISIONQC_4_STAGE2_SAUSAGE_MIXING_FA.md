# VisionQC 4.1 — مرحله دوم: محصول تخصصی دیگ اختلاط سوسیس

این نسخه مرحله دوم نقشه راه تجاری VisionQC است و فقط سناریوی «دیگ اختلاط سوسیس» را به سطح تخصصی‌تری رسانده است.

## تغییرات کلیدی

- افزوده‌شدن تحلیل زمانی واقعی برای ویدئو و دوربین:
  - ثبات حرکت
  - پوشش اختلاط
  - سلامت نواحی کم‌تحرک
  - ثبات زمانی فرایند
- تفکیک علمی عکس از ویدئو: شاخص‌های زمانی در عکس `NOT_APPLICABLE` هستند و دیگر صفر یا صد فرض نمی‌شوند.
- محدودکننده سلامت محصول: پایداری دستگاه نمی‌تواند محصول ضعیف را سالم اعلام کند.
- Triggerهای چندشاهدی برای اختلاط ناکافی و ناپایداری احتمالی امولسیون.
- Actionهای عملیاتی فارسی برای مدیر QC و اپراتور هدست.
- ارزیابی Trigger و تولید Action در Dry Run ویدئو.
- گزارش مدیریتی کوتاه همراه با محدودیت علمی و قابلیت ارزیابی تصویر.
- رفع سازگاری Runtime عملیاتی با شاخص‌های `NOT_APPLICABLE`.

## سیاست هوش مصنوعی

هوش مصنوعی فقط وقتی فراخوانی می‌شود که امتیاز نهایی کمتر از ۸۰ باشد یا Action مربوط به Trigger فعال آن را درخواست کند.

## محدودیت صنعتی

آستانه‌ها و وزن‌های فعلی یک Baseline مهندسی هستند. پیش از استفاده عملیاتی باید با ویدئوهای سالم و معیوب همان کارخانه، نور، دوربین، محصول و دستور تولید کالیبره شوند.
