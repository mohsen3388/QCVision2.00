# VisionQC 4.0 — Commercial Prototype

این نسخه بر پایه Phase 3 ساخته شده و مهاجرت یا بازنویسی کامل نیست.

## تغییرات اصلی

- Detector Registry واقعی و افزونه‌پذیر؛ هر شاخص به Detector اجرایی متصل است.
- Template صنعتی «کنترل دیگ اختلاط سوسیس» با ۱۲ شاخص و وزن‌های مستقل محصول/فرایند.
- Triggerهای چندشاهدی با Persistence برای کاهش هشدار کاذب.
- Actionهای قابل تنظیم برای داشبورد، هدست، Snapshot و هوش مصنوعی.
- Calibration Service برای پیشنهاد Threshold از نمونه‌های سالم و معیوب؛ انتشار خودکار انجام نمی‌شود و تأیید QC لازم است.
- گزارش مدیریتی مستقیم شامل وضعیت، سلامت محصول، سلامت فرایند، تصمیم و اقدام پیشنهادی.
- مراجعه به هوش مصنوعی فقط وقتی امتیاز تصمیم زیر ۸۰ باشد.

## قرارداد اصلی

Camera/Image/Video → Detector Plugin → Metric → Score → Trigger → Event → Action

## محدودیت علمی

شاخص‌های بصری جایگزین آزمون‌های شیمیایی، میکروبی یا اندازه‌گیری مستقیم دما و خلأ نیستند. Thresholdها باید در کارخانه و برای محصول، نور، دوربین و مرحله فرایند اعتبارسنجی شوند.
