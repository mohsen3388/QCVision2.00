# VisionQC — تفکیک سلامت محصول و سلامت فرایند

این نسخه نتیجه‌گیری همه مسیرها را به یک الگوی واحد تبدیل می‌کند:

- عکس: سلامت ظاهری محصول + قابلیت ارزیابی تصویر
- ویدئو: سلامت محصول + سلامت فرایند
- دوربین USB و IP: سلامت زنده محصول + سلامت زنده فرایند

سلامت محصول از رنگ، بافت، سطح، هوادهی، پوشش اختلاط و تطابق مرجع ساخته می‌شود و اولویت تصمیم دارد. سلامت بالای فرایند دیگر نمی‌تواند محصول نامطلوب را پنهان کند.

تحلیل عکس ساده‌تر و محافظه‌کارانه‌تر شده است. یک تشخیص منفرد حباب یا بازتاب نور به‌تنهایی وضعیت بحرانی ایجاد نمی‌کند و شاخص‌های زمانی در عکس به‌عنوان مدرک قطعی استفاده نمی‌شوند.

بازبینی هوش مصنوعی همچنان فقط برای امتیاز تصمیم نهایی کمتر از ۸۰ اجرا می‌شود.
