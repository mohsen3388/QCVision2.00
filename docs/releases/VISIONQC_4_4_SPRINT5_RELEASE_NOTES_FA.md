# VisionQC 4.4 — Sprint 5

## موضوع
Factory Memory، Root-Cause Feedback Loop و یادگیری از اقدامات اصلاحی.

## تغییرات
- صفحه جدید **Factory Learning** در منوی Quality.
- رتبه‌بندی علل تأییدشده، عیوب پرتکرار، دستگاه‌ها و شیفت‌های دارای تکرار بیشتر.
- محاسبه نرخ تکرار عیب و اثربخشی اقدامات دارای نتیجه.
- پیشنهاد اقدام از موارد مشابه فقط با اتکا به پرونده‌های تأییدشده QC.
- ثبت نتیجه «موثر/ناموثر» برای اقدامات اصلاحی و بازگشت آن به حافظه کارخانه.
- امکان تأیید فرضیه علت ریشه‌ای توسط مسئول QC در صفحه Root Cause Intelligence.
- نمایش محدودیت حجم داده و جلوگیری از تلقی همبستگی به‌عنوان علت قطعی.

## چرخه یادگیری
Inspection → Defect → Root-Cause Hypothesis → QC Confirmation → Corrective Action → Effectiveness Verification → Learned Recommendation

## محدودیت مهم
پیشنهادهای سیستم مشورتی هستند. علت ریشه‌ای و اقدام عملیاتی باید توسط مسئول QC یا مهندس فرایند تأیید شود.
