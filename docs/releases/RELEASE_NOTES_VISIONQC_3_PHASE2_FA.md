# VisionQC 3.0 Phase 2 — Configuration Studio

این نسخه نخستین پیاده‌سازی عملی معماری Zabbix-inspired برای پایش کیفیت صنایع غذایی است.

## قابلیت‌ها
- Quality Configuration Studio در منوی Configuration
- Template Builder
- Item/Metric Builder با اتصال اجباری به Detector
- Detector Registry داخلی
- Scoring قابل تنظیم از صفر تا صد
- Trigger Builder
- Action Builder
- Lifecycle و Production Gate
- Dry Run روی عکس و ویدئو
- Diagnostics، Audit، Import و Export
- Template نمونه اختلاط خمیر سوسیس

## مرز فاز دوم
در این فاز Studio و Runtime آزمایشی ساخته شده‌اند. اتصال Templateهای منتشرشده به اجرای دائمی چند دوربین، Event Correlation و Escalation کامل در فاز سوم تکمیل می‌شود.
