# VisionQC 2.0 — Sprint 2 Release Notes

## Factory Memory Foundation

Sprint 2 introduces the persistent knowledge layer required for future Root Cause Intelligence, Voice AI and Predictive Quality.

### New capabilities
- Factory Memory cases containing inspection, production and process context.
- Structured defect observations and supporting evidence.
- Corrective action recording and QC verification.
- Confirmed root-cause knowledge suitable for future learning.
- Offline similar-case retrieval.
- Event-driven integration with future dashboards, automation and voice modules.

### Compatibility
This release preserves the Sprint 1 architecture and the current VisionQC UI and feature set. The new services are registered in the application container and can be adopted incrementally by existing pages.
