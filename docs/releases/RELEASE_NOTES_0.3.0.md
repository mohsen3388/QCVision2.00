# VisionQC 0.4.1 — Sprint 3 Release Notes

This release introduces the first operational factory-knowledge feature: Golden Batch.

An approved profile captures the expected visual signature of a defined product, process stage and line. Current production images can be compared with that signature, with transparent per-metric deviations rather than a black-box verdict.

The feature is intentionally conservative: it presents visual similarity and escalation guidance, while final product acceptance remains the responsibility of qualified QC personnel and required laboratory/HACCP controls.
