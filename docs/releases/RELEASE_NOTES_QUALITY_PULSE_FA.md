# VisionQC Quality Pulse — Persian Dashboard

- 12 Persian quality indicators, each scored 0–100.
- Compact two-minute sparkline for every indicator.
- Live recommendations box combining local algorithmic advice and optional AI review.
- Provider-neutral user interface: the UI says «هوش مصنوعی» and does not expose a vendor name.
- Local-first escalation: routine monitoring remains local; AI review is requested only for meaningful changes, persistent deviations, predictive decline, and high-severity events.
- Added lightweight optical-flow based Motion Stability and Mixing Coverage indicators for video and live camera.
- Added scoring engine and regression tests.

Important: Motion, mixing coverage, surface, aeration, and reference scores are visual decision-support indicators and must be calibrated against the target product, camera, lighting, and approved factory samples before operational use.
