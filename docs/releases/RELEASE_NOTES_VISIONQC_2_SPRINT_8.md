# VisionQC 2.0 Sprint 8 Release Notes

## Release Candidate

This release adds production-readiness controls around the completed intelligence workflow: Factory Memory, Voice AI, Root Cause Intelligence, Knowledge Graph, Predictive Quality and AI Factory Engineer.

### New operational controls

- Release Candidate dashboard
- Append-only audit trail
- Database migration registry
- Automatic validated release backup
- Required/advisory release gates
- Exportable readiness report

### Safety boundary

A `Ready` result means automated software prerequisites passed. It does not replace factory installation qualification, operational qualification, performance qualification, cybersecurity review, food-safety validation, calibration, or user acceptance testing.
