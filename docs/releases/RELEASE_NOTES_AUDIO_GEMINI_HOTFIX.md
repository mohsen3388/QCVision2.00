# VisionQC 2.0 Audio and Gemini Review Hotfix

This hotfix changes only the agreed image/video review and headset behavior:

- Restores a separate **Gemini AI Review** tab for image and video analysis.
- Keeps **Operator Alert** as a separate concise operational tab.
- Adds **Tools > Audio Settings & Headset Test**.
- Routes speech through the Windows default output device and records audio diagnostics.
- Adds an English headset test message and a shortcut to Windows Sound Settings.
- Requests English-only Gemini inspection output.
- Converts operator voice alerts and emergency playbooks to English.
- Preserves silent monitoring for acceptable results and background recording for every analysis.

No other product module or workflow was intentionally changed.
