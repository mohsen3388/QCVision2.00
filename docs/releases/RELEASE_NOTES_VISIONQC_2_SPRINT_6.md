# VisionQC 2.0 — Sprint 6 Release Notes

## Predictive Quality

This release adds an offline-first, explainable early-warning capability. It forecasts short-horizon quality risk using comparable Factory Memory cases and shows the evidence behind every score.

### New
- Predictive Quality page with product, line and machine scope filters
- reject momentum and consecutive-reject detection
- repeated-defect growth detection
- process drift versus accepted baseline cases
- Low, Guarded, High and Critical risk bands
- predicted reject rate, confidence and limitations
- controlled recommended actions
- Voice AI questions for quality forecast and early warning
- domain events for forecast generation and high-risk warning

### Important
The forecast is decision support. It does not predict mechanical failure and does not authorize recipe, machine or process changes without qualified approval.
